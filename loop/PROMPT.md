# ④ 한 바퀴 도는 순서

읽기 → 하나만 만들기 → 실행해서 눈으로 확인 → 커밋 → STATUS.md 갱신

# ⑤ 커밋 순서 규칙

검사를 통과하면, 화면을 보기 "전에" 일단 커밋한다.
한 바퀴는 도중에 멈춘다. 멈춘 자리에 커밋이 없으면 그 작업은 사라진다.

④의 화면 확인 전에 검사 통과본을 먼저 커밋한다. 화면 확인 후 수정이 생기면
검사하고 다시 커밋한다. 마지막으로 `docs/STATUS.md`를 갱신하고 그 갱신도 커밋한다.

# ⑥ 검사와 QA

· 화면이 있는 것을 만들면, 실행해서 스크린샷을 찍고 그 이미지를
직접 읽어라. 코드가 도는 것과 화면이 괜찮은 건 다른 문제다.

· 같은 지적이 두 번 나오면 규칙으로 올리고, 기계가 잴 수 있는
규칙이면 검사로 만들어 둬라. 한 번 겪은 고장을 두 번 겪지 않는다.
